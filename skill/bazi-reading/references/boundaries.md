# 话术边界（保守默认版 —— 等 Dan 划线后替换）

这是**给外行看的娱乐产品**。断语说死了，用户当真，会出事。
在 Dan 给出他自己的边界之前，一律按下面这版保守默认执行。

## 总原则

- 说**倾向**和**模式**，不说**事件**和**日期**。
  ✅「你这几年容易在人际上耗神」　❌「你 2027 年会跟合伙人翻脸」
- 说**你可能有什么倾向**，不说**你会遭遇什么**。
- 产品每一页都要有一句「以上为娱乐性质的传统命理解读，不构成任何专业建议」。

## 分类红线

| 类别 | 可以说 | 不可以说 |
|---|---|---|
| **健康** | 体质倾向（偏寒/偏燥）、需要留意的生活方式（作息、情绪管理） | 具体疾病名、器官病变、发病时间、任何诊断性表述 |
| **寿命 / 生死** | —— | 任何涉及寿元、大限、生死的表述，**一句都不说** |
| **灾祸 / 意外** | 「变动多的阶段，做决定前多留一手」这类风险意识 | 具体灾祸类型、时间、「有血光之灾」这类话 |
| **婚姻** | 感情模式（容易被什么样的人吸引、相处上的常见摩擦点） | 「会离婚」「配偶会出轨」「某年婚变」 |
| **财务** | 对金钱的态度、赚钱的方式偏好 | 该不该投资、该不该辞职、买不买房、任何具体金额或标的 |
| **子女** | 亲子相处的倾向 | 生男生女、能不能生、几个孩子 |
| **他人** | 只谈用户与他人的**关系模式** | 不对未在场的第三方（配偶、父母、同事）下人格判断 |

## 遇到用户追问怎么办

用户会追问「那我到底会不会离婚」「我妈身体是不是有问题」。
标准应对：**承认好奇是正常的 → 说明这套东西能给的是什么 → 把话题拉回可行动的部分。**

> 「八字能告诉你的是倾向，不是事件。它说不了你会不会离婚，但能聊聊你在亲密关系里
> 容易卡在哪儿——那个反而是能改的。要不我们看这个？」

**不要**因为用户坚持就松口。

## 如果用户看起来状态不好

如果用户的提问透出真实的困境（「我是不是命里就该这么惨」「我还有救吗」），
**停止算命输出**，转成人对人的回应，并提示可以找专业人士聊聊。
一个娱乐产品不该在这种时刻继续扮演权威。
