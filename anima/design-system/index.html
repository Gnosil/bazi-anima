这一页是唯一真源的可视化。颜色/尺寸/动效改 tokens.js，这页自动跟着变。
核心约束：整数缩放、三档色阶、12 的倍数字号、steps() 动效。这四条是像素风「像不像」的全部。

01 网格与尺寸

一切尺寸都是 4px 的整数倍。精灵原始画布只有三种规格，放大只允许 2×/3×/4×，绝不允许 1.5×。

02 五行色板

每个五行三档：dark 阴影 / base 主体 / light 高光。像素画只用这三档——限制色阶是像素风的灵魂，多一档就糊。

五行图标（16×16，程序化绘制，无外部图片）

03 十神色板

十神有 10 个，配 10 种色相会糊。按五组分色相，组内用明暗区分阴阳——阳干用 light，阴干用 base。

07 动效规范

精灵动画统一 8 fps。复古手感来自低帧率，不是来自滤镜。
所有 CSS 过渡必须用 steps(n, end)。
禁止：ease-in-out / cubic-bezier / linear-gradient / 非整数 transform: scale() / border-radius / box-shadow 做柔和阴影。
时长三档：160ms / 320ms / 640ms。
